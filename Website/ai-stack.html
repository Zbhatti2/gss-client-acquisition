What Each AI/Model Does

The biggest beginner mistake is thinking every AI subscription is the same thing.

ThingUse It ForTalks to Homeowner Leads?
Base LLM Agents Us: research contractors, design workflows, write/inspect prompts, analyze failures, produce reports, troubleshoot. NO — not by itself
HighLevel Conversation AI Live approved SMS/chat conversations inside each client's HighLevel location; qualification and appointment/callback routing. YES — this is the launch customer-facing AI
HighLevel GPT Workflow step One-off text generation/classification/summarization inside a workflow. Default GPT-5 Mini is appropriate for routine tasks. Only if deliberately sent its output
OpenAI API Later custom automations outside ChatGPT/HighLevel. Separate billing and separate API key. OPTIONAL, later
Make Moves data between systems when native HighLevel connections are insufficient. NO — automation glue, not the chatbot

Exactly one system ever talks to your homeowner leads: the approved, client-specific Conversation AI. Everything else is either how we build/maintain it, or plumbing between systems.
