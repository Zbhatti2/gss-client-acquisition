Import Ads/Flyers (AI)

For ads and flyers collected before their business is necessarily in GSS yet — each photo is read by Claude for both the ad itself and the advertiser's own name/address/phone/website. Unlike Organizations > Import Ad(s) (which adds an ad to an organization you're already viewing), this can create a brand-new Organization — and a Contact too, if the ad names a specific person — so everything is staged for review before anything is saved. Nothing reaches your live data until you commit the batch.

Select as many individual photos as you like (up to {{ max_batch_images }} images per batch).
— or —
Use this instead of the file picker above for a large batch — same {{ max_batch_images }}-image limit either way.

A single photo can hold more than one distinct ad (e.g. several promos on one flyer, or a page of classifieds) — each one is extracted and staged separately.

Cancel

Requires an Anthropic API key configured on this server (ANTHROPIC_API_KEY environment variable). Already know which organization this ad belongs to? Open that organization's page and use its own "Import Ad(s)" button instead — that flow stays exactly as it was.
