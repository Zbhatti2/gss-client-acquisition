Controls the contact form on your organization's own public website. A submission there is added directly to Client Acquisition as a new Organization, Contact, and Opportunity — no login required on the website's side. It's authenticated instead by the token below, embedded in that website's code.

Notification email

Every new website lead sends a short email here, in addition to appearing in Client Acquisition.

Intake token

Identifies your organization to the lead-intake endpoint — anyone with this token can add a lead to your pipeline, and nothing else, so it's safe to embed in your website's public code (see the snippet below), but don't share it anywhere unrelated to that.

Website snippet

Paste this into your website's contact-form handler — it POSTs the form fields to Client Acquisition. organization_name and at least one of contact_name/ contact_email/contact_phone are required; message is optional. The website field is a spam trap — leave that input on the page but hidden from real visitors (e.g. positioned off-screen), never filled in.

fetch("{{ request.url_root.rstrip('/') }}{{ url_for('public_leads.submit_lead') }}", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    token: "{{ tenant.lead_intake_token }}",
    organization_name: form.organization_name.value,
    contact_name: form.contact_name.value,
    contact_email: form.contact_email.value,
    contact_phone: form.contact_phone.value,
    message: form.message.value,
    website: form.website.value  // honeypot -- must stay empty
  })
})
  .then(r => r.json())
  .then(data => { if (data.ok) { /* show a thank-you message */ } else { /* show data.error */ } });
