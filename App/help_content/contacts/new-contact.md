**Full name** is the only required field — everything else (title, suffix,
organization, job title, profession, context, and multiple emails/phones/
addresses) can be filled in now or added later from the contact's own
page.

## File As

Leave **File As** blank and GSS falls back to sorting by full name. Set it
explicitly when you want this contact to file somewhere else in the
list — for example, sorting a company switchboard contact under the
organization's name instead of a person's name.

## Linking to an Organization

Picking **Organization** here links this contact as currently working
there — it drives the "Contacts" list on that organization's own page. A
contact isn't required to have an organization at all.

## Assistant

A contact can have another contact on file as their Assistant — useful
for routing correspondence. This is just a link to an existing contact,
not a separate kind of record.
