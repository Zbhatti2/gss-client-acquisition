Click **New Entry** from a table's list. Only **Label** is required.

## Code

**Code** is optional but must be unique within the table if you set it —
useful if you're integrating with an import/export format that expects a
stable machine-readable key rather than the display label.

## Sort order

Most tables list alphabetically by Label, so **Sort order** doesn't
control what you see on the list — it's there for the rare table (like
Organization Size Categories) whose entries have a real logical
progression rather than an alphabetical one.

## Active

Uncheck **Active** to hide an entry from new selections everywhere it's
picked from, without deleting it or affecting records that already use
it. This is the safer choice over deleting whenever you're not sure
something is fully unused.
